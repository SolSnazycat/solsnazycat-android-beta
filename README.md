# SolSnazycat Android beta

Download the signed Android beta and read the installation notes on the [SolSnazycat Android Beta page](https://solsnazycat.ca/android-beta/). The APK is also available from the [v0.1.4-beta GitHub prerelease](https://github.com/SolSnazycat/solsnazycat-android-beta/releases/tag/v0.1.4-beta).

## Report an app problem

[Open a bug report](https://github.com/SolSnazycat/solsnazycat-android-beta/issues/new/choose). Include your phone model, Android and app versions, browsing mode, and the steps needed to reproduce the issue.

Issues are public. Remove names, addresses, order numbers, payment details, and account information from text and screenshots. For help with an order or account, [contact SolSnazycat](https://solsnazycat.ca/) through the store.

The app connects to the live storefront. Completing checkout places a real order.
